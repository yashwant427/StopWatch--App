# ⏱️ Stopwatch App

A simple and responsive **Stopwatch App** built using HTML, CSS, and JavaScript.

The stopwatch allows users to start, stop, and reset the timer with a simple and interactive interface.

## 🚀 Features

- ▶️ Start the stopwatch
- ⏹️ Stop the stopwatch
- 🔄 Reset the stopwatch
- ⏱️ Displays hours, minutes, and seconds
- ⚡ Real-time timer updates
- 🎨 Simple and clean user interface
- 📱 Responsive design
- 🔧 Built using vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- `setInterval()`
- Event Handling
